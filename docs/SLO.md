# SLO / SLI

SLIs: p50/p95/p99 latency, throughput, error rate, concurrency/saturation, dependency health and resource usage.

Baseline: p95 end-to-end latency < 500 ms; p99 < 1 s; dropped/degraded items are measurable.

Reference target only; calibrate with production traffic before declaring a contractual SLO.
